Sistem Prezență USV
Aplicație web pentru gestionarea prezenței studenților în sălile de curs ale Universității Ștefan cel Mare din Suceava. Permite vizualizarea ocupării locurilor în timp real, autentificarea studenților și generarea de coduri QR pentru înregistrarea prezenței.

Tehnologii folosite:
        Next.js (App Router)
        TypeScript
        CSS Modules
        React (useState, hooks)

În lucru / Urmează:
        Integrare librărie QR real (qrcode.react)
        Pagina /admin — panou cu statistici și prezențe
        Pagina /afisor-sala — ecran cu locurile pentru afișaj sală
        Conectare Supabase — bază de date și real-time
